# 真实天气接入

## 使用方法

1. 重启后端，在微信开发者工具重新编译。
2. 农户首页选择地块，进入“灾害预警”。
3. 搜索附近城市或乡镇（中文未匹配时尝试拼音），从候选列表选择位置；也可以填写准确的 WGS84 经纬度。
4. 核对位置，选择作物，点击“保存位置并查询真实天气”。
5. 查看含今天在内的三天预报、风险日期、项目风险等级、措施、来源和获取时间。

原有“示范区”不是实际地名，不会自动映射到任意城市。地块的经纬度初次确认后保存在已有 plots 字段中，无需修改数据库结构。城市中心坐标只能代表区域，地块坐标更准确。小程序不会自动采集手机定位。搜索词及查询坐标会发送至对应天气服务，用户身份、数据库密码不发送。

## 天气来源

- 预报：[Open-Meteo Forecast API](https://open-meteo.com/en/docs)。
- 地点搜索：[Open-Meteo Geocoding API](https://open-meteo.com/en/docs/geocoding-api)。
- 当前采用免密钥公共接口，适用于本课程非商业用途；免费接口有使用量限制，未来商业用途应按[服务条款](https://open-meteo.com/en/terms)配置对应方案。数据署名 Open-Meteo，CC BY 4.0。
- 时间口径统一为 Asia/Shanghai。获取过去7个完整日和含今天在内的3天数据；历史字段是模型天气数据，不宣称为地面观测。
- 气温为2米高度日最低/最高气温；降雨使用 rain_sum + showers_sum。历史少雨天数使用包含雪的总降水 precipitation_sum，避免把降雪误算成无降水。
- 获取时间是本系统请求时间，不冒充模型发布时间。返回的网格坐标可能略偏离地块坐标。

## 风险规则 weather-v2

以下为项目参考规则，不是官方预警信号，不表示模型已验证的农业损失概率。

| 类别 | 条件 | 说明 |
|---|---|---|
| 强降雨 | 当日雨量≥50毫米，中；≥80毫米，高 | 每个预报日单独判断，采用北京时间自然日累计 |
| 少雨高温缺水 | 截至昨日连续≥3天总降水<1毫米，今日最高温≥30℃且今日总降水<10毫米 | 连续≥7天标高，窗口最多7天，页面显示“至少7天”；未结合土壤湿度 |
| 霜冻风险 | 日最低温≤0℃，中；≤-3℃，高 | 2米气温筛查，不保证覆盖地表霜冻，也不是作物专属耐受阈值 |
| 作物低温适配 | 最低温>0℃但低于作物库生长温度下限 | 与霜冻分开显示，不再将番茄15℃生长下限当成霜冻阈值 |

本版规则位于服务代码中；旧灾害规则表未删除，但不再作为 weather-v2 的触发依据。规则维护界面仍属后续工作。

## 接口与失败行为

- `PUT /api/plots/:id/location`：验证坐标范围与地块所有者，保存经纬度。
- `GET /api/disaster-alerts/locations?name=...`：返回候选地点供用户确认，不自动选择。
- `GET /api/disaster-alerts?plotId=...&cropName=...`：服务端从数据库取地块坐标获取天气，不信任客户端天气参数。
- 按坐标和北京时间日期缓存10分钟，最多200项；不返回过期缓存。单次外部调用超时12秒，网络异常最多重试一次；上游限流不自动重试。
- 无坐标返回400，越权/不存在返回404，缺失天气返回502，网络失败返回503。
- 天气失败不回退模拟值，不把 null 转为0，不返回 normal。页面清除旧结果并提示重试。
- 身份仍沿用现有演示请求头；本次接入没有替代尚未完成的微信身份验证。
