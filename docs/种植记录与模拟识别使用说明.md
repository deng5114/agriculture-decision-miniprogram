# 种植记录与模拟识别

## 使用步骤

在 server 目录运行 `npm run dev`，然后在微信开发者工具重新编译。

1. 选择“种植农户”登录。
2. 首页点击“我的种植记录”，可按草稿、待审核、已通过、已驳回筛选。
3. 点击“新增种植记录”，或在地块卡片点击“填写种植记录”。
4. 选择已有地块，填写作物、日期（选填）、预算、经验和问题描述。
5. 选择“保存草稿”或“保存并提交审核”。提交后记录变为只读。
6. 已驳回记录可修改、再次提交，表单和列表保留最近审核意见。

没有地块时可从表单进入“新增地块”，保存后返回继续填写。现有记录不能更换地块。

## 模拟识别范围

本版使用确定的样例数据，不启用麦克风、相机或照片上传，不调用真实语音或图像模型。

- 语音成功样例：“种两亩番茄，地块缺水”“种三亩玉米”。
- 图片成功样例：番茄、玉米。
- 失败样例：噪声/无声、模糊图片、无关图片。
- 成功后显示可修改候选字段，点击“确认并填入表单”才改变作物和问题字段；仍需另行保存。
- 取消、失败或网络异常时保留原表单，可重试或手动填写。
- 语音样例中的面积仅供核对；面积来自选定地块，不会自动覆盖地块。图片样例没有问题字段时不覆盖原问题描述。

## 新增接口

`POST /api/recognition/voice`、`POST /api/recognition/image` 接收 `{ "sample": "tomato" }`。其他样例键为 `corn`、`noise`、`blurred`、`unrelated`。成功响应包含 `isMock`、`recognized`、`requiresConfirmation` 和候选 `fields`；识别失败返回 `recognized: false` 和手动填写提示。接口不写入数据库。

`GET /api/plant-records/:id` 返回本人记录详情和 YYYY-MM-DD 日期。草稿修改和提交接口增加状态条件，避免提交后的记录被覆盖。预算、日期、字段长度在服务端验证。

当前身份仍沿用已有演示请求头，仅用于本地课程联调，尚未接入真实微信身份。
