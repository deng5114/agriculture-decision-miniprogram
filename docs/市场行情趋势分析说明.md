# 市场行情趋势与年度变化分析

## 功能范围

市场行情页支持按作物、区域和年份区间查询，并新增以下展示：

- 价格、产量、种植面积三类年度折线图，可点击切换指标；
- 每个年度相对于上一自然年的价格、产量和面积同比变化；
- 价格首末年变化、年度均价、最高/最低价格年份和波动等级；
- 数据来源、单位、聚合方式和分析边界说明。

## 统计口径

1. 同一作物、同一区域、同一年份若存在多条记录，接口按各指标平均值聚合为一个年度数据点，来源字段合并去重。
2. 同比只在两个数据点属于相邻自然年时计算。年份有缺口时显示 `--`，不把跨年变化冒充年度同比。
3. 趋势使用查询区间首末年价格变化率描述：大于 3% 为“上升”，小于 -3% 为“下降”，其余为“基本平稳”。
4. 波动使用年度价格的变异系数描述：低于 10% 为“波动较低”，10% 至 20% 为“波动中等”，20% 及以上为“波动较高”。
5. 以上结果是对已有历史数据的规则化描述，不构成未来价格预测或经营承诺。

## 接口

`GET /api/market-data?cropName=番茄&region=示范区&startYear=2022&endYear=2024`

接口要求登录请求头，并返回 `rows`、`analysis`、`dataSource` 和 `statisticNote`。查询年份限制为 1900—2100，一次最多查询连续 21 年。

## 验证

在 `server` 目录执行：

```powershell
node --test test/market.test.js
```

测试覆盖年度排序、相邻年同比、年份缺口、零基数、单年数据、前端格式化、数据库年度聚合和非法年份校验。
