# 种植记录与真实语音、植物图片识别

## 已实现流程

### 语音识别

1. 农户点击“开始真实语音识别”并授予麦克风权限；
2. 小程序以 16 kHz、单声道、48 kbps 录制最长 20 秒的音频；
3. 音频通过 `wx.uploadFile` 上传到项目后端；
4. 后端调用百度智能云短语音识别，将录音转换为文字；
5. 后端从文字中提取已启用的作物名称、亩数和常见问题关键词；
6. 小程序展示候选结果，用户确认或修改后才填入表单。

### 图片识别

1. 农户拍照或从相册选择植物图片；
2. 小程序压缩图片并上传到项目后端；
3. 后端调用百度智能云植物识别；
4. 页面显示最可能的植物、置信度和最多三个候选项；
5. 置信度达到配置阈值后，用户仍需确认才能填入作物字段。

文件仅在后端内存中用于本次识别，不写入数据库或项目目录。录音和图片上限为 4MB，其中植物图片限制为 3MB，以满足云端 Base64 大小要求。

## 百度智能云配置

1. 登录[百度智能云控制台](https://console.bce.baidu.com/ai/#/ai/speech/app/list)，创建应用并开通“短语音识别”。
2. 在图像识别服务中开通[植物识别](https://cloud.baidu.com/product/imagerecognition/plant)。
3. 将同一应用的 API Key 和 Secret Key 写入 `server/.env`：

```dotenv
BAIDU_AI_API_KEY=你的API_Key
BAIDU_AI_SECRET_KEY=你的Secret_Key
BAIDU_ASR_DEV_PID=1537
RECOGNITION_MIN_CONFIDENCE=0.5
```

4. 重启后端。页面显示“百度智能云 · 已配置”后即可使用。

密钥只能放在后端 `.env` 中，禁止写入小程序代码、提交到 GitHub 或截图公开。

## 微信配置

- 本地模拟器可使用 `http://127.0.0.1:3000`；手机真机调试时，后端地址必须改为手机可访问的局域网或 HTTPS 地址。
- 发布前需在微信公众平台将后端 HTTPS 域名加入 `request` 和 `uploadFile` 合法域名。
- 在微信公众平台完成麦克风、相机/相册用途的隐私保护指引声明。
- `miniprogram/app.json` 已加入录音权限用途说明。

## 接口

- `GET /api/recognition/status`：返回服务是否已配置，不返回任何密钥；
- `POST /api/recognition/voice`：字段 `file`，并带 `format=m4a`；
- `POST /api/recognition/image`：字段 `file`，支持 JPG、PNG、BMP；
- 两个识别接口均要求农户身份，返回 `isMock: false` 和待确认候选结果。

## 测试

在 `server` 目录执行：

```powershell
node --test test/records-recognition.test.js
```

自动化测试使用模拟的云端 HTTP 响应，不消耗真实额度；它验证了真实文件上传协议、鉴权缓存、语音字段提取、植物候选、未配置密钥、权限控制，以及候选结果不得直接覆盖表单。最终上线前还应使用本人凭证在真机上各测试一次录音和植物照片。
