# 管理员统计图表与面积口径说明

## 问题原因

原统计接口把审核通过的种植记录与地块连接后，直接执行 `SUM(地块面积)`。当一个地块存在多条审核通过记录时，该地块面积会随记录条数被重复累加。

例如，面积为 6.5 亩的同一地块有 3 条通过记录，旧口径会得到 19.5 亩，实际涉及的唯一地块面积仍为 6.5 亩。

## 修正后的口径

- 通过记录数：按审核通过的种植记录计数；
- 预算合计：按审核通过的种植记录预算求和；
- 汇总面积：按唯一地块计数，同一地块只累加一次；
- 区域分类面积：按该区域内的唯一地块计数；
- 作物分类面积：按唯一“地块＋作物”组合计数，同一地块同一作物的多条记录只累加一次。

一个地块若登记了不同作物，会分别进入对应作物分类，因此各作物分类面积之和可能大于汇总面积，不应把作物分类面积直接相加作为实际总面积。

## 图表

管理员页面新增作物分布和区域分布横向条形图，支持在“去重面积”和“审核通过记录数”之间切换。图表最多展示数值最高的 8 项，完整数据仍在下方分类明细中展示。

## 测试

在 `server` 目录执行：

```powershell
node --test test/statistics.test.js
```

测试覆盖重复记录面积去重、跨作物口径、空数据、图表比例、未审核记录排除和管理员权限校验。
