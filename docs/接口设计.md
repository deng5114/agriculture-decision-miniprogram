# 农业作物智能决策小程序接口设计

## 1 接口约定

- 基础路径：`/api`
- 数据格式：JSON
- 成功响应：`{ "code": 0, "message": "ok", "data": {} }`
- 失败响应：`{ "code": 非0, "message": "错误说明", "data": null }`
- 受保护接口使用登录后的用户身份；后端必须再次校验角色和数据归属。

## 2 认证与用户

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/auth/login` | 演示登录并返回用户身份 | 公开 |
| GET | `/users/me` | 查询当前用户 | 登录用户 |
| GET | `/users` | 查询用户列表 | 管理员 |
| PUT | `/users/:id/role` | 修改用户角色 | 管理员 |

## 3 地块与种植记录

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/plots` | 创建地块 | 农户 |
| GET | `/plots` | 查询本人地块 | 农户 |
| GET | `/plots/:id` | 查询地块详情 | 所有者或授权角色 |
| POST | `/plant-records` | 创建种植记录或草稿 | 农户 |
| PUT | `/plant-records/:id` | 修改草稿或驳回记录 | 所有者 |
| POST | `/plant-records/:id/submit` | 提交审核 | 所有者 |
| GET | `/plant-records` | 查询记录 | 按角色过滤 |

## 4 推荐、行情和预警

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/recommendations` | 根据地块条件计算推荐 | 农户 |
| GET | `/market-data` | 查询作物、区域和年份行情，返回年度聚合、同比及趋势分析 | 登录用户 |
| GET | `/disaster-alerts` | 查询灾害预警和措施 | 登录用户 |
| POST | `/recognition/voice` | 模拟语音转文字 | 农户 |
| POST | `/recognition/image` | 模拟图片识别候选字段 | 农户 |

## 5 审核和统计

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| GET | `/reviews/pending` | 查询待审核内容 | 农技人员 |
| POST | `/reviews/:id/approve` | 审核通过 | 农技人员 |
| POST | `/reviews/:id/reject` | 驳回并填写原因 | 农技人员 |
| GET | `/statistics/region` | 查询区域统计 | 管理员 |
| GET | `/knowledge` | 查询已审核知识 | 登录用户 |
| POST | `/knowledge` | 提交知识或合作信息 | 农技/从业者 |

## 6 错误处理

- 必填字段缺失：返回 `400`。
- 无登录身份：返回 `401`。
- 角色不足：返回 `403`。
- 访问他人私有数据：返回 `403` 或空数据。
- 资源不存在：返回 `404`。
- 接口异常：返回 `500`，前端显示可理解的错误提示。
- 空行情或天气数据：返回成功状态和空数据说明，页面显示“暂无数据”，不能白屏。
