# 农业作物智能决策微信小程序

面向农村种植场景的微信小程序课程项目，提供种植信息填报、作物规则推荐、市场行情、灾害预警、农技审核和区域统计功能。

## 技术方案

- 前端：微信小程序原生开发（WXML、WXSS、JavaScript）
- 后端：Node.js + Express
- 数据库：MySQL
- 图表：ECharts
- 推荐方式：可解释的规则驱动评分
- 代码管理：GitHub

## 项目目录

```text
miniprogram/   微信小程序前端
server/        Node.js 后端
database/      数据库脚本和测试数据
docs/          需求、设计、测试和过程文档
screenshots/   界面截图
```

## 当前状态

项目已完成本地代码仓库初始化，正在进行系统设计和数据库设计。

## 说明

语音识别、图片识别、天气数据和市场数据在第一版中采用可替换的模拟数据或服务接口，识别失败时保留手动录入入口。
